# 《影之刃零》销量预测局

一个可复用的中文游戏销量预测投票页面，默认由 6 位玩家预测游戏正式发售后 3 个月的全球累计销量。

## 功能

- 默认 6 个席位，姓名唯一，支持修改已提交的预测。
- 销量以“万份”为单位，支持快捷填写和可选判断依据。
- 默认全员提交后揭晓，也可切换为实时展示。
- 自动计算平均值、中位数、最高值、最低值和预测跨度。
- 支持复制结果、清空本局，以及修改游戏、周期、人数和单位。
- 适配桌面和手机屏幕，浏览器本地保存记录。

## 本地运行

无需安装前端依赖。在本目录运行：

```sh
python -m http.server 4173
```

浏览器访问 http://localhost:4173 。

## 文件

- `index.html`：页面结构。
- `styles.css`：样式和响应式布局。
- `app.js`：投票、校验、统计和本地保存逻辑。

静态托管时将仓库根目录设为发布目录即可。

## 使用范围

本版本适合同一设备上轮流投票。记录仅保存在当前浏览器，不会在不同设备之间同步。若要多人各自使用手机共同投票，需要增加共享后端和参与者身份验证。

字体从 Google Fonts 加载，网络不可用时会使用系统字体。

销量预测仅供娱乐，不代表官方数据。
